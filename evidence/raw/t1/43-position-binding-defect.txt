# Position binding defect — deterministic reproduction (RED)
# UTC: 2026-10-21T11:29:33Z
# Local Foundry only; no RPC, no keys. FR-041(8) and contracts/merkle.md say a proof for index i
# never verifies at j != i. With leafHash = keccak256(0x00 || data) that is false when two
# adjacent blocks are byte-identical: nodeHash(L, L) makes their proofs interchangeable.
#
# First found by the T009a fuzz campaign (persisted counterexample countSeed=108, indexSeed=511,
# lenSeed=0 -> leafCount 45, index 16, verified at 17; fuzz seed 0xb9b20a43...). The 1-byte
# leaves collided into an identical sibling pair. The cache file was deleted after diagnosis;
# this 4-leaf case is the minimal deterministic reproduction and needs no cache.
